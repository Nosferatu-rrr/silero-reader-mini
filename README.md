# Silero Reader Mini

**Silero Reader Mini** — это легкое и удобное приложение для озвучивания текста (TTS) на базе нейросетевых моделей Silero. Программа разработана с упором на минимализм, высокую скорость работы и комфортное чтение длинных текстов.

## Основные возможности

*   **Мгновенный старт:** Интерфейс загружается сразу, а модель подгружается в фоне.
*   **Динамическая подсветка:** Текущее читаемое предложение выделяется в тексте, окно автоматически прокручивается за диктором.
*   **Умные паузы:** Настройка задержек между предложениями и абзацами для максимально естественной речи.
*   **Упреждающий синтез:** Пока вы слушаете текущую фразу, программа уже готовит следующую — никаких задержек.
*   **Фильтрация текста:** Автоматическая обработка ссылок и спецсимволов.
*   **Экспорт в MP3:** Сохранение озвученного текста в аудиофайл.
*   **Сохранение настроек:** Программа запоминает выбранный голос, скорость и настройки пауз.

## Установка и запуск (Linux)

### 1. Требования
Для работы необходим Python 3.10+ и `ffmpeg`.

```bash
sudo apt update && sudo apt install ffmpeg
```

### 2. Быстрый старт
```bash
git clone https://github.com/ваше-имя/silero-reader-mini.git
cd silero-reader-mini
python3 -m venv venv
source venv/bin/activate
pip install torch numpy sounddevice soundfile pydub
./run.sh
```

## Технологии
*   Движок: Silero TTS
*   Интерфейс: Tkinter
*   Аудио: Sounddevice, Pydub
