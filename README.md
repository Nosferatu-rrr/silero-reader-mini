# Silero Reader Mini

**Silero Reader Mini** — это легкое и функциональное приложение для озвучивания текста (TTS) на базе нейросетевых моделей Silero. Программа сочетает минималистичный интерфейс и продвинутые возможности для комфортного чтения книг и статей.

## Основные возможности

*   **⚡ Мгновенный старт:** Интерфейс появляется сразу, тяжелая модель подгружается в фоне.
*   **🎯 Чтение с любого места:** Просто кликните мышкой по любому предложению в тексте, и диктор продолжит чтение именно оттуда.
*   **🧠 Память позиции:** Программа запоминает текст и точное место, где вы закончили слушать, даже после перезагрузки.
*   **🔢 Умная озвучка цифр:** Автоматическое преобразование чисел в слова на русском языке (например, "2026" → "две тысячи двадцать шестой").
*   **🔤 Транслитерация латиницы:** Автоматическое преобразование английских слов в кириллицу (например, "Python" → "Пытхон"), чтобы диктор не замалчивал иностранные слова.
*   **📂 Работа с файлами:** Меню для быстрого открытия любых `.txt` файлов с поддержкой кодировок UTF-8 и Windows-1251.
*   **💾 Быстрый экспорт в MP3:** Многопоточная запись аудио с отображением реального прогресса в процентах прямо на кнопке.
*   **🔍 Визуальный комфорт:** Динамическая подсветка текущей фразы и автоматическая прокрутка текста (автоскролл).
*   **🛠 Тонкая настройка:** Удобное управление голосами, скоростью речи и паузами между предложениями/абзацами.
*   **🔄 Смена версии модели:** Переключение между версиями Silero TTS прямо из меню «Настройки → Модель» (с автоматическим откатом при ошибке загрузки).
*   **⬇️ Проверка обновлений:** Пункт «Настройки → Модель → Проверить обновления» подтягивает новые версии из официального `models.yml`.
*   **🖱 Контекстное меню:** Полноценная работа правой кнопкой мыши (Вырезать, Копировать, Вставить).

## Установка и запуск (Linux)

### 1. Требования
Необходим Python 3.12, установленный `ffmpeg` (для экспорта в MP3) и библиотеки для работы с аудио.

```bash
sudo apt update && sudo apt install ffmpeg libportaudio2
```

Установите менеджер пакетов [uv](https://github.com/astral-sh/uv):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Установка
```bash
# Python 3.12 (если в системе другая версия)
uv python install 3.12

# Создание виртуального окружения через uv
uv venv --python 3.12

# Установка зависимостей (CPU-сборка torch, без CUDA)
uv pip install -r requirements.txt
uv pip install --index-url https://download.pytorch.org/whl/cpu --reinstall-package torch torch
```

> **Важно:** версия Python в окружении должна совпадать с той, на которой создавался `venv`. После обновления системы `/usr/bin/python3` может смениться (например, 3.12 → 3.14), и тогда `venv/bin/python` начнёт указывать на новый интерпретатор, а пакеты останутся в каталоге старой версии — приложение перестанет видеть модели. Проверка: `venv/bin/python -V`.

### 3. Запуск
```bash
./run.sh
```

## Технологии
*   **Движок:** Silero TTS v5 (актуальная версия с улучшенным качеством речи)
*   **Интерфейс:** Python Tkinter
*   **Аудио:** Sounddevice (воспроизведение), Pydub (склейка и экспорт)
*   **Текст:** Num2Words (конвертация чисел), Simple Translit (латиница -> кириллица)

## Версии модели

Доступные версии задаются в словаре `AVAILABLE_MODELS` в начале `main.py`. Это офлайн-фолбэк: список работает без интернета. Чтобы добавить новую версию вручную, достаточно дописать одну строку:

```python
AVAILABLE_MODELS = {
    "v5_6_ru": "https://models.silero.ai/models/tts/ru/v5_6_ru.pt",
    ...
}
```

Выбор версии — в меню **Настройки → Модель**. Выбранная версия сохраняется в `settings.json` и подгружается при следующем запуске. Если модель не загрузилась, приложение автоматически откатывается на рабочую версию.

### Проверка обновлений

Пункт **Настройки → Модель → Проверить обновления** скачивает официальный список `models.yml` из репозитория `snakers4/silero-models` и автоматически добавляет в меню новые версии русских моделей. Так приложение не отстаёт от релизов, но продолжает работать и без интернета (на статическом списке).

## Устранение неполадок

**«Не удалось загрузить модель» при выборе любой версии.**
Проверьте, что окружение видит torch:

```bash
./venv/bin/python -c "import torch; print(torch.__version__)"
```

Если выводится `ModuleNotFoundError`, значит `venv` создан на другой версии Python, чем та, на которую указывает `venv/bin/python` (типично после обновления Ubuntu). Лечится пересозданием окружения:

```bash
mv venv venv.broken
uv venv --python 3.12 venv
uv pip install --python venv/bin/python -r requirements.txt
uv pip install --python venv/bin/python --index-url https://download.pytorch.org/whl/cpu --reinstall-package torch torch
```

**Модель загружается, но интерфейс остаётся в «Запуск...».**
В сборке Tk 9.0 из Ubuntu отключена поддержка потоков (`tcl_platform(threaded)` отсутствует), поэтому `root.after()` из фонового потока не выполняется. В актуальном `main.py` все обновления UI идут через очередь `ui_queue` (`post_ui()`), проблема устранена. Если вы откатываетесь на старый код — обновитесь до текущей версии.
