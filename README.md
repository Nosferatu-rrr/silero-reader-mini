# Silero Reader Mini

**Silero Reader Mini** — это легкое и функциональное приложение для озвучивания текста (TTS) на базе нейросетевых моделей Silero. Программа сочетает минималистичный интерфейс и продвинутые возможности для комфортного чтения книг и статей.

## Основные возможности

*   **⚡ Мгновенный старт:** Интерфейс появляется сразу, тяжелая модель подгружается в фоне.
*   **🎯 Чтение с любого места:** Просто кликните мышкой по любому предложению в тексте, и диктор продолжит чтение именно оттуда.
*   **🧠 Память позиции:** Программа запоминает текст и точное место, где вы закончили слушать, даже после перезагрузки.
*   **🔢 Умная озвучка цифр:** Автоматическое преобразование чисел в слова на русском языке (например, "2026" → "две тысячи двадцать шестой").
*   **📂 Работа с файлами:** Меню для быстрого открытия любых `.txt` файлов с поддержкой кодировок UTF-8 и Windows-1251.
*   **💾 Быстрый экспорт в MP3:** Многопоточная запись аудио с отображением реального прогресса в процентах прямо на кнопке.
*   **🔍 Визуальный комфорт:** Динамическая подсветка текущей фразы и автоматическая прокрутка текста (автоскролл).
*   **🛠 Тонкая настройка:** Удобное управление голосами, скоростью речи и паузами между предложениями/абзацами.
*   **🖱 Контекстное меню:** Полноценная работа правой кнопкой мыши (Вырезать, Копировать, Вставить).

## Установка и запуск (Linux)

### 1. Требования
Необходим Python 3.10+ и установленный пакет `ffmpeg` (для экспорта в MP3).

```bash
sudo apt update && sudo apt install ffmpeg
```

### 2. Установка
```bash
git clone https://github.com/Nosferatu-rrr/silero-reader-mini.git
cd silero-reader-mini
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Запуск
```bash
./run.sh
```

## Технологии
*   **Движок:** Silero TTS v4
*   **Интерфейс:** Python Tkinter (Toplevel, Menu)
*   **Аудио:** Sounddevice (воспроизведение), Pydub (склейка и экспорт)
*   **Текст:** Num2Words (конвертация чисел)
